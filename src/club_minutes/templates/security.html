Passphrase

{{ 'set' if passphrase_set else 'not set' }}

Set on the server only, so a stolen admin sign-in can't change it: CLUB_MINUTES_BACKUP_PASSPHRASE=… (12+ characters) in /etc/club-minutes/env, then restart the app. Keep a copy in your password manager and a printed one somewhere safe at the club: without it no backup opens. A new one applies to new backups only, so keep the old one until the old backups have aged out.

Suggest a passphrase

{{ suggestion }}

Random, made just now and not kept anywhere: copy it before leaving the page. Capitals and digits without look-alikes (no 0/O, 1/I/L), in groups of four, easy to read off paper; about 119 bits. A password manager's generator works too: 20+ random letters and digits, or 7+ random words.

Whether it matches the server's, how strong it is, and whether it's among Have I Been Pwned's leaked passwords (only the first 5 characters of its hash are sent). It isn't stored or logged.
