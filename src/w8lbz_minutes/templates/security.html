The passphrase

Set on the server only, in /etc/w8lbz-minutes/env (W8LBZ_BACKUP_PASSPHRASE=…, then restart the app), so a stolen admin sign-in can't change it. Keep it in your password manager, and a printed copy somewhere safe at the club: without it no backup opens. Changing it affects only new backups; keep the old one until the old backups have aged out.

Random, made just now and not kept anywhere: copy it before leaving the page. Capital letters and digits without look-alikes (no 0/O, 1/I/L), in groups of four, so it's easy to read off paper and type; about 119 bits, far beyond guessing. A password manager's generator works too: 20+ random letters and digits, or 7+ random words. Symbols aren't needed: length matters more.

Says whether it matches the server's, how strong it is, and whether it's in Have I Been Pwned's leaked passwords (only the first 5 characters of its hash are sent). It isn't stored or logged.

Recommended: daily at {{ rec.hour }}:00, keep {{ rec.keep_local }} on the server, {{ rec.drive_keep }} on Google Drive, and {{ rec.s3_days }} days on S3 (the bucket's lifecycle rule). At this size{% if backup_status.size %} (about {{ (backup_status.size / 1048576)|round(1) }} MB each){% endif %}, a year of daily backups is a few GB at most: pennies on B2, well within a Shared Drive. Daily means at most a day of changes could be lost; the server copies cover a mistake noticed within the week, the off-server copies a lost server or one noticed later.
